## Editar y regenerar

Los diseños están en `catalogo.html` (una `<section>` por pieza). Después de editar:

```bash
node catalogo-whatsapp/render.mjs   # requiere playwright
```

Las cifras de los mockups (+38 %, 4.9 ★, $ 4.8M, etc.) son ilustrativas: ajustalas a casos reales si las vas a usar como prueba de resultados.
